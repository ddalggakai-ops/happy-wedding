# 모바일 청첩장 · 배포 가이드

형규 ♥ 현진 모바일 청첩장 소스코드입니다. **HTML 한 장 + 이미지 폴더**로 이루어진 정적(static) 사이트라, 별도 서버나 빌드 과정 없이 어디서든 바로 올려서 배포할 수 있습니다.

> 현재는 **가짜 데이터 + 자리표시(placeholder) 이미지**가 들어 있습니다. 아래 안내에 따라 내용과 사진만 바꾸면 그대로 완성됩니다.

---

## 1. 폴더 구조

```
wedding-invitation/
├── index.html            ← 청첩장 본문 (여기서 텍스트 수정)
├── README.md             ← 이 안내서
└── assets/
    ├── cover.jpg         ← 메인(커버) 사진 1장
    ├── bgm.mp3           ← 배경음악 (직접 넣어야 함, 지금은 없음)
    └── gallery/
        ├── 01.jpg ~ 12.jpg   ← 갤러리 사진 12장
```

## 2. 미리보기 (내 컴퓨터에서 확인)

`index.html` 파일을 크롬 등 브라우저로 그냥 열면 바로 보입니다.
(단, 폰트·지도는 인터넷 연결이 있어야 정상 표시됩니다.)

---

## 3. 내 사진으로 바꾸기

`assets` 폴더 안의 파일을 **같은 이름으로 덮어쓰기** 하면 끝입니다.

| 항목 | 파일 | 권장 크기 |
|------|------|-----------|
| 커버(메인) 사진 | `assets/cover.jpg` | 세로형, 880×1200px 이상 |
| 갤러리 사진 | `assets/gallery/01.jpg` ~ `12.jpg` | 세로형, 600×720px 이상 |

- 파일 이름과 확장자(`.jpg`)를 그대로 유지하세요.
- 사진 개수를 바꾸고 싶으면 `index.html` 안의 `var TOTAL = 12;` 숫자를 바꾸고 그만큼 파일을 넣으면 됩니다. (`var VISIBLE = 9;` 는 "더보기" 누르기 전에 보이는 장수)

## 4. 배경음악 넣기

원하는 음원 파일을 `assets/bgm.mp3` 이름으로 넣으면 우측 상단 버튼으로 재생됩니다.
(파일이 없으면 버튼만 표시되고 소리는 나지 않습니다. 저작권 있는 음원은 사용에 유의하세요.)
※ 모바일 브라우저 정책상 자동재생은 막혀 있어, 방문자가 버튼을 눌러야 재생됩니다.

## 5. 문구 바꾸기 (`index.html` 열어서 수정)

메모장·VS Code 등에서 `index.html`을 열고 아래 항목을 찾아 바꾸세요.

- **전화번호**: `010-0000-0000` (신랑/신부 전화·문자용)
- **인사말**: `소중한 분들을 초대합니다` 아래 문단
- **예식장**: `웨딩피치홀`, `3층 그랜드볼룸`, `서울특별시 마포구 양화로 45`
- **계좌번호**: `카카오뱅크 3333-01-0000000` 등 각 계좌 줄
- **캘린더·D-day**: 스크립트 안 `var year=2026, month=10, wedDay=15;` 숫자만 바꾸면 달력과 D-day가 자동 계산됩니다.

## 6. 지도 바꾸기

`index.html`에서 `maps.google.com/maps?q=...` 부분의 주소를 실제 예식장 주소(또는 예식장 이름)로 바꾸면 됩니다. 예:
```
src="https://maps.google.com/maps?q=예식장이름 또는 도로명주소&z=16&output=embed"
```
주소에 한글이 있어도 그대로 넣으면 대부분 동작합니다.

## 7. 배포하기 (무료 호스팅 3가지 중 택1)

### 방법 A — Netlify Drop (가장 쉬움, 추천)
1. https://app.netlify.com/drop 접속
2. `wedding-invitation` **폴더를 통째로** 드래그&드롭
3. 몇 초 뒤 `https://랜덤이름.netlify.app` 주소가 생성됩니다 → 이 링크를 카톡으로 공유
4. (선택) 무료 회원가입 후 사이트 이름을 `hyeongkyu-hyunjin` 처럼 바꿀 수 있습니다.

### 방법 B — Vercel
1. https://vercel.com 가입 → **Add New → Project**
2. 폴더를 올리면 자동 배포 → `https://프로젝트이름.vercel.app` 주소 생성

### 방법 C — GitHub Pages
1. 깃허브에 새 저장소(repository) 생성 후 이 폴더 내용을 업로드
2. **Settings → Pages → Branch: main / root** 선택 후 저장
3. 잠시 뒤 `https://아이디.github.io/저장소이름` 으로 공개

> 세 방법 모두 폴더 구조(`index.html`이 최상단, `assets/`가 그 아래)를 그대로 유지해야 사진이 정상 표시됩니다.

## 8. 카카오톡 공유 썸네일 (선택, 고급)

`index.html` 상단 `og:title` / `og:description` 을 수정하면 링크 공유 시 제목·설명이 바뀝니다.
공유 이미지 썸네일까지 넣으려면 `<meta property="og:image" content="이미지 URL">` 을 추가하세요.
카카오톡 "카카오톡 공유" 버튼을 실제 공유 팝업으로 동작시키려면 Kakao Developers의 JavaScript 키가 필요합니다(선택 사항이며, 없어도 "링크 복사"로 공유 가능).
